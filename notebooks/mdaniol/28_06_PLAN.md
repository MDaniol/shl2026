## 3. Frozen-FM compliance boundary (for the paper's "frozen" claim)
Two tests: **(A)** modifies any backbone param (weights/bias/its LayerNorm affines)? **(B)** requires
gradient *through* the frozen backbone? Strict "frozen" = **pass both**.

| Technique | Verdict |
|---|---|
| Linear/any head on cached emb; **LST side-net**; layer-attention probe; FiLM-on-cached-emb | **ALLOWED ✓** (forward-only) |
| BitFit, LayerNorm/affine tuning, LP-FT, full fine-tuning | **FORBIDDEN** (modify backbone params) |
| SSF, LoRA (merge into weights); adapters, prompt/prefix/VPT (backprop through backbone) | **GRAY → avoid** |
| Learned input-adapter trained via grad-through-FM | **defer**; use *label-free* gravity-canonicalization instead |

**Paper line:** state explicitly that adapters/LoRA/prompt/SSF/BitFit/LN-tuning were *deliberately excluded*
to preserve a forward-only frozen guarantee — all trainable params live outside the backbone with no
gradient through it. LST + layer-attention + FiLM-on-cached-emb instantiate exactly that.
